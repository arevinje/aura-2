### Installation

See [`INSTALL-ENGLISH.md`](english/INSTALL-ENGLISH.md) for complete installation instructions.

Quick summary:
1. Install button-card via HACS
2. Copy `www/aura/motor.js` to `/config/www/aura/motor.js`
3. Create new dashboard with `docs/english/aura_dashboard_english.yaml`
4. Customize entities in `mitt_hem` block

### Testing

Open [`test-offline.html`](english/test-offline.html) in your browser to validate the installation before deploying to Home Assistant.
